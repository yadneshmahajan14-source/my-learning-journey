## 🧑‍💻 Project 1: Student Study Planner

A beginner-friendly Python project that collects student study details and displays a simple study plan.

### Features
- Collects the student's name.
- Accepts the subject to study.
- Records planned study hours.
- Displays a motivational message.

### Technologies Used
- Python 3
- GitHub

### How to Run
1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run `python student_planner.py`.
